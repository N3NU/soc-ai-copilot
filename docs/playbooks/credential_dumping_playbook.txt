TITLE: Credential Dumping Playbook

DOCUMENT_TYPE: playbook

CATEGORY: credential_access

DEPARTMENT: incident_response

SEVERITY: critical

VERSION: 1.0

CLASSIFICATION: confidential

LAST_UPDATED: 2026-05-24

PURPOSE:
Defines procedures for suspected credential dumping activity.


INDICATORS:
- LSASS access
- Mimikatz execution
- Credential theft alerts
- Memory dump creation


INITIAL_ACTIONS:
1. Identify affected host
2. Preserve evidence
3. Determine exposure scope


CONTAINMENT:
- Isolate host
- Disable compromised accounts


ERADICATION:
- Remove malicious tools
- Rotate credentials


RECOVERY:
- Restore account access


COMMUNICATION:
- Notify IAM team


ESCALATION:
- Escalate privileged account involvement


REFERENCES:
- Credential Security SOP
